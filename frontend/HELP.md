# 使用帮助(FAQ)

本文档面向学习者,汇总「多智能体助教助学系统」前端的常见问题。代码细节
可查阅 `frontend/` 目录,环境准备与启动方式见仓库根目录 `README.md`。

## 如何触发审批?

把任务直接发给 Supervisor(在对话输入框正常提问即可,Supervisor 是协作流程
的调度角色)。当任务需要分派给助教 / 助学 / 评价 Agent 时,对话区会出现审批
卡片,你可以在卡片上确认、拒绝,或修改目标 Agent 与任务内容后再提交,审批
结果会继续进入同一轮对话。

## 多智能体结果如何呈现?

专业 Agent 作为 Supervisor 的内部工具运行。Supervisor 会等待子任务完成、整合
结果后，在原始对话中逐步输出最终回答；页面不再展示单独的协作过程面板。这样切换
会话或刷新页面后，用户看到的始终是已持久化的问答历史，而不是临时运行事件。

## 归档会话如何恢复?

当前版本支持查看归档会话:侧栏底部「归档」开关打开后,归档会话出现在归档
区,可重新选中查看历史消息。恢复(取消归档)需要后端新增 unarchive 能力——
core 的 `SessionStore` 目前只有 create / list / archive(见 D4-T7 降级记录),
前端不做越界调用。

## 常见错误是什么意思?

错误提示文案统一来自 `frontend/lib/error-messages.ts` 的映射表:`session_busy`
(会话正忙,稍后重试)、`model_call_failed`(模型服务暂不可用)、
`handoff_not_pending`(审批已被处理)、网络失败(检查连接后重试)等;未知错误
码会落到「出了点问题」兜底文案。

## 如何启用语义检索?

默认部署使用词法检索(永不降级的底线)。需要真实语义检索时,在 `backend/`
下执行 `uv sync --extra embedding` 安装 fastembed,再用
`uv run python scripts/ingest_books.py --force --vector --provider fastembed`
重建向量库(注意 fastembed 的 512 维向量与哈希库的 256 维不同,重建前先删旧
`data/vector_knowledge.db`)。详见仓库根目录 `README.md`「启用真实语义检索
(可选)」。

## 暗色模式与移动端怎么用?

右上角月亮 / 太阳按钮切换亮色 / 暗色主题,选择会持久保存。移动端顶栏左侧的
汉堡按钮打开会话侧栏抽屉,选中会话或点击遮罩自动收起;Esc 也可关闭抽屉。

## 流式中断了如何重试?

回答过程中点「停止生成」会中断当前流,已收到的内容保留。若请求因网络或
模型错误失败,错误块会提供重试入口(网络失败时按钮文案为「重新发送上一条
消息」,基于 `lastSentMessage` 重发);断线重连通道(指数退避 +
`fromSequence` 续传)会先自动重试,耗尽后才降级提示。
