# 典型问题测试案例规程（赛题维度 5：内容质量度）

> 赛题硬性要求：提供至少 3 个典型问题的测试案例，并展示输出结果的准确性论证（与标准答案的对比、引用权威来源的佐证等）。
> 赛题点名的三类学科问题：公式推导、代码调试、概念辨析。本规程按三类各 1-2 题执行，产出《典型案例测试报告》归入《07—其他材料》，其中 1-2 例同时作为 3 分钟演示视频的问答片段。
> 学科口径：人工智能（机器学习/深度学习），与知识库入库教材一致（保证引用可追溯）。

## 一、选题清单（各选 1-2 题，优先与入库教材章节对应）

### A 类：概念辨析
- 备选 1：偏差-方差分解（偏差与方差的权衡，过拟合的成因辨析）
- 备选 2：批归一化与层归一化的区别与适用场景
- 论证要点：回答须区分易混淆概念、给出适用条件；与教材定义逐句对照。

### B 类：公式推导
- 备选 1：反向传播中链式法则的逐层梯度推导（以 sigmoid + 均方误差为例）
- 备选 2：逻辑回归交叉熵损失对权重的梯度推导
- 论证要点：每一步变换可核对；最终梯度表达式与教材/标准答案一致；回答含引用标注（document/page）。

### C 类：代码调试
- 备选 1：一段含 broadcasting 错误的 NumPy 前向计算代码
- 备选 2：学习率与梯度更新符号写反的 PyTorch 训练循环
- 论证要点：系统须定位错误行、解释错因、给出修正后代码；修正版可实际运行（本地运行截图作为可执行验证）。

## 二、执行步骤（每题一致，保证可复现）

1. 新建干净会话（独立 `X-User-Id`：`case-a/b/c`），避免上下文污染。
2. 以自然语言提问（一次提问，不追加提示词技巧——展示默认能力）。
3. 完整保存：问题原文、系统回答全文（含引用列表截图）、响应耗时。
4. 对回答中每条引用执行可追溯核验：点开引用（document/page）→ 与知识库原文对照 → 记录"引用属实/不属实"。
5. 准确性论证（三选一或组合）：
   - 与标准答案逐步对比（制作对照表：推导步骤 | 系统输出 | 标准答案 | 一致性）；
   - 引用权威来源佐证（教材页码截图 + 系统引用标注截图并置）；
   - 可执行验证（代码类：修正代码运行输出截图）。
6. 若回答有瑕疵：如实记录 + 记录点踩/纠错反馈（诚实呈现比全对更可信）。

## 三、《典型案例测试报告》结构模板

```
1. 测试环境：模型与版本、知识库规模（文档数/分块数）、检索配置（混合检索+重排，见 .env）
2. 案例 A 概念辨析
   2.1 问题原文
   2.2 系统输出（截图 + 全文摘录）
   2.3 准确性论证（对照表/权威引用）
   2.4 引用可追溯核验记录
   2.5 结论（正确/部分正确/错误 + 说明）
3. 案例 B 公式推导（同结构，附逐步推导对照表）
4. 案例 C 代码调试（同结构，附运行验证截图）
5. 汇总：3+ 案例通过率、引用属实率、平均响应耗时
```

## 四、与系统能力的对应关系（写入报告"技术支撑"段）

- 引用可追溯：核心层引用真实性校验（剔除伪造/越界引用，见 `backend/src/core/graph_builder.py` _verify_references）——引用非模型自报，经检索命中比对；
- 知识权威：知识库为入库教材（`data/books/`），混合检索 + Cross-Encoder 重排保证命中质量；
- 评价闭环：每题可追加"请评价你的回答"触发 evaluator 结构化评价（pass/questionable/fail），评价截图可作辅助证据。
